Statement reading (optional)

The Import page uses Claude to read statements. Paste an Anthropic API key from console.anthropic.com to turn it on. The key is saved only in this browser, and each statement read is billed to that key (usually a few pesos).

Back up to this device

Downloads everything (expenses, categories, budget) as one file. Keep it somewhere safe, such as Google Drive.

Export to a spreadsheet (CSV)

One row per expense with date, category, subcategory, note, payment method, amount and source. Opens in Excel or Google Sheets. CSV files can't be restored; use the backup file for that.

Leave the dates blank to export everything.

Restore from a backup file

Choose an Expense Tracker backup file, including one downloaded from the claude.ai version. Entries already in your ledger are skipped, so nothing is duplicated. Categories and budget are replaced by the backup's.
